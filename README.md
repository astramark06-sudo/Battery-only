# BatteryScope

Standalone Android battery and device telemetry project. The application source, engineering records and APK build workflow are being separated from the OCR/AI Operations Platform.

- Source migration: [advanced BatteryScope branch](https://github.com/astramark06-sudo/ocr/tree/c3cc95cf2dfa29e3c85af02c2aa65fc769635b7d/BatteryScope)
- OCR and Python platform: [ocr](https://github.com/astramark06-sudo/ocr)

No signing keys, private device logs or generated APKs belong in this repository.
